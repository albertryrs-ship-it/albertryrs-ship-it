## `01` — Profile

I'm **Julio Alberto Reyes**, a Software Engineering student at UNICAES in El Salvador, interested in the intersection of **data, software, and business operations**.

I enjoy designing data models, building applications around real operational workflows, and turning structured information into useful reports and decisions. My current focus is **Data Analytics, Business Intelligence, relational databases, and data-oriented software systems**.

- **Focus:** Data Analytics · Business Intelligence · SQL · Data Modeling
- **Engineering:** APIs, application architecture, integrations, and automation
- **Building with:** Wuju DEV and independent software projects
- **Currently exploring:** Better ways to make data traceable, accessible, and actionable

> I care about the full path from reliable data to a useful product: model it, process it, present it, and make it support better decisions.
